# How to run 
1. Easiest option: open the live website in your browser at https://cj-252.github.io/
2. If you want to run it on your computer, click the green "Code" button on GitHub and choose "Download ZIP."
3. Find the downloaded ZIP file in your Downloads folder, then right-click it and choose "Extract All."
4. Open the extracted folder, then double-click the file named index.html.
5. Your web browser will open the page. If it does not open automatically, right-click index.html and choose "Open with," then select your browser.

# Troubleshooting
1. The page opens as plain text/code instead of a webpage:
	Make sure you opened the file named index.html in a web browser (Chrome, Edge, Firefox), not in a text editor.
2. Images are missing:
	Confirm the images folder is in the same project folder as index.html and was extracted from the ZIP.
3. Styles are missing (page looks plain):
	Make sure style.css is in the same folder as index.html.
4. Buttons or interactions do not work:
	Make sure script.js and main.js are in the same folder as index.html.
5. I changed files but do not see updates:
	Save your file, then refresh the browser with Ctrl + R (or click the refresh button).
